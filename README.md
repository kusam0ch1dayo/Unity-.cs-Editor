# Unity-.cs-Editor

ブロックを組み合わせて、Unity 用の C# スクリプトを作れるブラウザアプリです。
C# を読み込んでブロックに戻すこともできます。

**▶ [ブラウザですぐに試す](https://kusam0ch1dayo.github.io/Unity-.cs-Editor/)** (インストール不要・アプリとしてインストールも可)

## 使い方

`index.html` をブラウザで開くだけで動きます (インストール不要)。
ライブラリは `vendor/` に同梱しているので、**インターネット接続なしでも動きます**。
GitHub Pages などで公開した場合も、一度開けば次からはオフラインで使えます (サービスワーカー `sw.js`)。

1. 左のカテゴリからブロックをドラッグして組み立てる
2. 右側にリアルタイムで C# が表示される
3. 「コピー」または「.cs 保存」で Unity の Assets に入れる

## 初心者向けの機能

- **📚 学ぶ (チュートリアル)**: 6 つのレッスン (Hello World・変数で動かす・if・for・当たり判定・C# を読む)。指示どおりにブロックを置くと自動で合格判定されます
- **ヘルプ**: ブロックを選ぶと、やさしい説明・コツ・C# での書き方・公式ドキュメントへのリンクを表示。ブロックにマウスを乗せても説明が出ます
- **エラーのやさしい説明**: エラーの意味と直し方を、ヘルプと「問題」の各行 (マウスを乗せる) で表示
- **ヒント**: 「Time.deltaTime を掛け忘れ」「Update で GetComponent」など、Unity でよくある失敗を自動で指摘
- **🔰 かんたんモード**: よく使うブロック (約 60 種類) だけを表示
- **はじめての案内**: 初回に、チュートリアル・テンプレート・自由に作る から選べます

## 主な機能

- **ブロック → C#**: 約 220 種類のブロック。クラス・フィールド・メソッド・Unity イベント (2D 物理・Gizmos 含む)・コルーチン・リスト・辞書・配列・Raycast (3D / 2D)・UI・サウンド・アニメ・PlayerPrefs・ラムダ式・try / catch・文字列補間・属性 ([Header] など)・コメントなど
- **エラーチェック**: C# 文法チェック (tree-sitter) と、未定義の変数・型の不一致などの意味チェック。エラーのあるブロックには警告アイコンが付きます
- **Tab 補完**: 入力欄で変数名・型・メンバーの候補を表示し、Tab で確定
- **取り消し / やり直し**: ボタン、Ctrl+Z / Ctrl+Y (Ctrl+Shift+Z)
- **C# → ブロック**: 「C# 読込」で既存の .cs をブロックに変換。専用ブロックがない構文は「C# 文 / 式 / メンバー」ブロックで残します
- **読み込みログ**: 足りないブロックを一覧表示し、追加依頼の文章 (Markdown) にまとめられます
- **タブ**: 複数のスクリプトを切り替えて編集。「全部 zip」でまとめて保存。ほかのタブのクラスもエラーチェックと補完で使えます
- **テンプレート**: 2D / 3D の移動、カメラ追従、敵の生成、HP、スコア、弾、アイテム、制限時間、タイトル画面
- **ブロック検索**: Ctrl+K で検索欄へ。「音」「ジャンプ」などの日本語でも探せます
- **ブロックとコードの対応**: ブロックを選ぶと C# の該当行がハイライト。行をクリックするとブロックを選択
- **ワンクリック修正**: つづり間違いの修正、足りないフィールドやメソッドの作成をボタンで
- **名前の一括変更**: 右クリック →「名前を一括変更」または F2
- **メモ**: 右クリック →「コメントを追加」でブロックにメモ。「メモ出力」で C# のコメントにもできます
- **メニューとショートカット**: 右上の ✏️ 編集 / 📁 ファイル / 🔰 初心者 から操作を選べます。⚙ 設定でよく使う操作をヘッダーのショートカットに追加・並べ替えできます
- **ダークモード**: ⚙ 設定で 自動 / ライト / ダーク
- **C# を直接編集**: 右側の「✏️ C# を編集」で C# を書き換え、「ブロックに反映」(Ctrl+Enter) でブロックに戻せます (構文エラーがある間は反映できません)
- **プロジェクトファイル**: 全タブを 1 つの `.json` に保存・読み込み (ファイル メニュー)
- **URL で共有**: 今のタブを圧縮してリンクにします。開いた人は新しいタブで読み込めます (公開したページで使えます)
- **編集履歴**: 2 分ごと・全消去や読み込みの前に自動で記録し、あとから戻せます (最大 30 件)
- **マイブロック**: ブロックを右クリック →「マイブロックに登録」で、よく使うまとまりをツールボックスに追加できます
- **アプリとしてインストール (PWA)**: 公開したページから、設定 メニューの「アプリとしてインストール」で追加できます。新しい版が出ると「再読み込み」のお知らせが出て、更新後に「新しくなった点」を表示します
- **Unity の Assets に直接保存**: 設定で Assets (または Assets/Scripts) フォルダを選ぶと、Ctrl+S でそこに .cs を保存します (Chrome / Edge)。アプリが書いていない同名ファイルは、上書きの前に確認します
- **C# の貼り付け**: どこかでコピーした C# (クラス・メンバー・文・式) を Ctrl+V すると、選んでいる場所にブロックとして入ります。ブロックを Ctrl+C すると C# もコピーされます
- **対象の Unity バージョン**: 設定で Unity 6 / 2022 を選ぶと、名前が変わった API (`velocity` → `linearVelocity` など) を警告し、ワンクリックで直せます
- **性能のヒント**: Update の中の GetComponent / Find を、ワンクリックで「Start で 1 回だけ取得してフィールドに入れる」形に書き換えます
- **変更点の比較**: 編集履歴と今の状態、C# 編集の前後を色付きで比較できます
- **折りたたみ・整列**: 編集メニューから、メソッドをまとめて折りたたむ・すべて開く・整列
- **タブ**: 複製・ドラッグで並べ替え・閉じたタブを開き直す (Alt+Shift+T)・右クリックメニュー
- **表示の設定**: C# の文字サイズとブロックの大きさを変えられます
- **基本のブロック**: Invoke / CancelInvoke、Time.timeScale、タグで全部探す、親子の操作、リストの初期化・ランダムな要素・集計 (合計・最大・平均など)、文字の置き換え・分割、辞書の TryGetValue など (`js/packs/basics.js` の標準パックとして、既存のカテゴリに追加)
- **Unity のエラーから探す**: Unity の Console のエラー (コンパイル・実行時) を貼り付けると、原因と直し方を説明し、その行のブロックへ移動します
- **インスペクターのプレビュー**: public / [SerializeField] のフィールドが Unity のインスペクターでどう見えるかを表示します ([Header] [Range] [Tooltip] [Space] [TextArea] [HideInInspector] に対応)
- **目次と使っている場所**: クラス・変数・メソッドの一覧から移動でき、選んだ変数やメソッドを使っているブロックが光ります
- **コマンドパレット (Ctrl+Shift+P / F1)・次のエラーへ (F8)・最近使ったブロック**
- **画像で保存**: ブロック全体、または右クリックで 1 つのブロックを PNG / SVG で保存できます
- **コードの書き方と名前のチェック**: `{` の位置 (次の行 / 同じ行) と字下げ (空白 4 / 2 / タブ) を選べます。メソッドは大文字・変数は小文字で始める、などの決まりを警告してワンクリックで直せます
- **設定の引っ越し**: テーマ・ショートカット・マイブロック・拡張パックなどを 1 つのファイルで書き出し / 読み込みできます
- **テーマ**: 設定の「テーマ」タブで、明るさ (自動 / ライト / ダーク)・テーマカラー (8 色)・コードの配色・ブロックの色の鮮やかさ (落ち着いた / 鮮やか / とても鮮やか) を選べます。アクセント・背景・パネル・文字・コードの背景の色は自分で変えられます (ライト用とダーク用を別々に保存)
- **拡張パック**: ブロックを JSON だけで追加できます (C# 生成・読み込み・チェック・説明も自動)。標準で AI ナビゲーション (NavMesh) と Input System のパック入り。形式は [docs/block-packs.md](docs/block-packs.md)
- **English UI**: ⚙ 設定で日本語 / English を切り替え (初回はブラウザの言語に合わせます)

| `js/i18n.js` | 表示言語 (日本語 / English) の辞書と切り替え |

| `js/blocks.js` | ブロックの見た目と入出力の定義 |
| `js/generator.js` | ブロック → C# コード生成 |
| `js/toolbox.js` | ツールボックスとサンプルプログラム |
| `js/types.js` | 型情報 (Unity API・メンバー・スコープ・型推論) |
| `js/checker.js` | エラーチェック (意味チェック・構文チェック) |
| `js/autocomplete.js` | Tab 補完 |
| `js/importer.js` | C# → ブロックの読み込みと読み込みログ |
| `js/app.js` | 起動と画面操作 (保存・取り消し・ダイアログなど) |
| `js/theme.js` | ダークモード |

| `js/project.js` | タブ (複数スクリプト) と zip 保存 |

| `js/packs.js` | 拡張パックの仕組み。`js/packs/` に標準のパック |
| `js/projectfile.js` | プロジェクトファイル (.json)・URL での共有・編集履歴 |
| `js/snippets.js` | マイブロック |
| `js/editor.js` | C# の直接編集とブロックへの反映 |
| `js/pwa.js` | アプリとしてインストール・更新のお知らせ・新しくなった点 |
| `js/assets.js` | Unity の Assets フォルダへの直接保存 |

| `js/learn.js` | ヘルプ・エラーの説明・ヒント・チュートリアル・かんたんモード・はじめての案内 |

| `manifest.webmanifest`, `icons/` | アプリとしてインストールするときの名前とアイコン |
| `tests/` | 自動テスト (`npm test`)。GitHub Actions で push のたびに実行 |
| `vendor/` | 同梱ライブラリ (Blockly・tree-sitter)。詳細は `vendor/README.md` |

ビルドは不要です。JS は通常の `<script>` で上から順に読み込み、グローバルの定数・関数を共有しています。

## 自動テスト

```sh
npm ci
npx playwright install chromium
npm test
```

ブラウザ (Chromium) でアプリを開き、全ブロックの C# 生成・C# の読み込み (`tests/fixtures/`)・テンプレート・チュートリアル・英語表示・オフライン動作・拡張パック・保存 / 共有 / 履歴 / マイブロック / C# 編集を確かめます。GitHub Actions (`.github/workflows/test.yml`) でも push のたびに実行されます。

## 制限

- 本物の C# コンパイラではありません。Unity API は主要なものだけ確認します
- 読み込み時、namespace と、式の途中やクラスの外にあるコメントは省略されます
