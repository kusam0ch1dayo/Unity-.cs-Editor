# Unity-.cs-Editor

ブロックを組み合わせて、Unity 用の C# スクリプトを作れるブラウザアプリです。
C# を読み込んでブロックに戻すこともできます。

## 使い方

`index.html` をブラウザで開くだけで動きます (インストール不要)。
ライブラリは `vendor/` に同梱しているので、**インターネット接続なしでも動きます**。
GitHub Pages などで公開した場合も、一度開けば次からはオフラインで使えます (サービスワーカー `sw.js`)。

1. 左のカテゴリからブロックをドラッグして組み立てる
2. 右側にリアルタイムで C# が表示される
3. 「コピー」または「.cs 保存」で Unity の Assets に入れる

## 主な機能

- **ブロック → C#**: 約 220 種類のブロック。クラス・フィールド・メソッド・Unity イベント (2D 物理・Gizmos 含む)・コルーチン・リスト・辞書・配列・Raycast (3D / 2D)・UI・サウンド・アニメ・PlayerPrefs・ラムダ式・try / catch・文字列補間・属性 ([Header] など)・コメントなど
- **エラーチェック**: C# 文法チェック (tree-sitter) と、未定義の変数・型の不一致などの意味チェック。エラーのあるブロックには警告アイコンが付きます
- **Tab 補完**: 入力欄で変数名・型・メンバーの候補を表示し、Tab で確定
- **取り消し / やり直し**: ボタン、Ctrl+Z / Ctrl+Y (Ctrl+Shift+Z)
- **C# → ブロック**: 「C# 読込」で既存の .cs をブロックに変換。専用ブロックがない構文は「C# 文 / 式 / メンバー」ブロックで残します
- **読み込みログ**: 足りないブロックを一覧表示し、追加依頼の文章 (Markdown) にまとめられます
- **タブ**: 複数のスクリプトを切り替えて編集。「全部 zip」でまとめて保存。ほかのタブのクラスもエラーチェックと補完で使えます
- **テンプレート**: 2D / 3D の移動、カメラ追従、敵の生成、HP、スコア、弾、アイテム、制限時間、タイトル画面
- **ブロック検索**: Ctrl+K で検索欄へ。「音」「ジャンプ」などの日本語でも探せます
- **ブロックとコードの対応**: ブロックを選ぶと C# の該当行がハイライト。行をクリックするとブロックを選択
- **ワンクリック修正**: つづり間違いの修正、足りないフィールドやメソッドの作成をボタンで
- **名前の一括変更**: 右クリック →「名前を一括変更」または F2
- **メモ**: 右クリック →「コメントを追加」でブロックにメモ。「メモ出力」で C# のコメントにもできます
- **ダークモード**: 右上のボタンで 自動 / ライト / ダーク

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | 画面の HTML。各ファイルを読み込む |
| `css/style.css` | 見た目 (ライト / ダークモード対応) |
| `js/blocks.js` | ブロックの見た目と入出力の定義 |
| `js/generator.js` | ブロック → C# コード生成 |
| `js/toolbox.js` | ツールボックスとサンプルプログラム |
| `js/types.js` | 型情報 (Unity API・メンバー・スコープ・型推論) |
| `js/checker.js` | エラーチェック (意味チェック・構文チェック) |
| `js/autocomplete.js` | Tab 補完 |
| `js/importer.js` | C# → ブロックの読み込みと読み込みログ |
| `js/app.js` | 起動と画面操作 (保存・取り消し・ダイアログなど) |
| `js/theme.js` | ダークモード |
| `js/search.js` | ブロック検索 |
| `js/refactor.js` | 名前の一括変更 |
| `js/project.js` | タブ (複数スクリプト) と zip 保存 |
| `js/templates.js` | テンプレート集 |
| `sw.js` | オフライン用のサービスワーカー |
| `vendor/` | 同梱ライブラリ (Blockly・tree-sitter)。詳細は `vendor/README.md` |

ビルドは不要です。JS は通常の `<script>` で上から順に読み込み、グローバルの定数・関数を共有しています。

## 制限

- 本物の C# コンパイラではありません。Unity API は主要なものだけ確認します
- 読み込み時、namespace と、式の途中やクラスの外にあるコメントは省略されます
